# 🎵 레코드 감지 기능 (Record Detection)

## 개요
턴테이블에 레코드가 놓여있는지 감지하여, 레코드가 있을 때만 소리가 나도록 하는 기능입니다.

## 🎯 주요 기능
- **실시간 레코드 감지**: 카메라를 통해 턴테이블에 레코드가 있는지 실시간으로 감지
- **자동 소리 제어**: 레코드가 없으면 소리 끄기, 있으면 소리 켜기
- **다양한 감지 방법**: 색상 분석, 템플릿 매칭, 엣지 분석 지원
- **GUI 통합**: 메인 턴테이블 GUI에 완전히 통합

## 🔧 사용 방법

### 1. 메인 GUI에서 사용
```bash
# 턴테이블 GUI 실행
./run_turntable.sh
```

1. **레코드 감지 활성화**: GUI의 "레코드 감지" 섹션에서 체크박스 활성화
2. **기준 설정**: 프로그램 시작 시 자동으로 빈 턴테이블 기준 데이터 수집
3. **실시간 감지**: 레코드를 놓고 빼면서 실시간으로 감지 상태 확인

### 2. 독립 테스트
```bash
# 레코드 감지 테스트 실행
./run_record_test.sh
```

## 🎛️ 설정 옵션

### 감지 방법 (Detection Methods)
- **color_analysis** (기본값): 색상 히스토그램 분석
- **template_matching**: 템플릿 매칭
- **edge_analysis**: 엣지 밀도 분석

### 주요 매개변수
- **threshold**: 레코드 감지 임계값 (0.0 ~ 1.0, 기본값: 0.6)
- **baseline_frames**: 기준 데이터 수집 프레임 수 (기본값: 30)
- **smoothing_factor**: 결과 스무딩 팩터 (0.0 ~ 1.0, 기본값: 0.8)

## 🔍 작동 원리

### 1. 기준 데이터 수집
- 프로그램 시작 시 빈 턴테이블 상태를 기준으로 데이터 수집
- 30프레임 동안 색상/패턴 정보 수집

### 2. 실시간 감지
- 각 프레임을 기준 데이터와 비교
- 유사도가 낮을수록 레코드가 있을 가능성이 높음
- 스무딩을 통해 안정적인 결과 제공

### 3. 소리 제어
- 레코드 감지됨 → MIDI 노트 생성 및 전송
- 레코드 없음 → 모든 MIDI 노트 끄기

## 🎨 시각적 피드백

### GUI 오버레이
- **녹색 원**: 레코드 감지됨
- **빨간색 원**: 레코드 없음
- **신뢰도 표시**: 0.0 ~ 1.0 사이의 값

### 상태 표시
- "레코드 상태: 레코드 있음 ✅" / "레코드 상태: 레코드 없음 ❌"
- "신뢰도: 0.85" 형태로 실시간 업데이트

## 🛠️ 고급 설정

### config.json에서 설정
```json
{
  "record_detection": {
    "enabled": true,
    "method": "color_analysis",
    "threshold": 0.6,
    "baseline_frames": 30,
    "smoothing_factor": 0.8
  }
}
```

### 코드에서 직접 설정
```python
from utils.record_detector import create_record_detector

detector = create_record_detector(
    method="color_analysis",
    threshold=0.6,
    baseline_frames=30,
    smoothing_factor=0.8
)
```

## 🔧 문제 해결

### 1. 잘못된 감지
- **임계값 조정**: GUI에서 "기준 재설정" 버튼 클릭
- **조명 개선**: 일정한 조명 환경에서 사용
- **ROI 조정**: 감지 영역을 적절히 설정

### 2. 느린 반응
- **baseline_frames 감소**: 기준 수집 프레임 수 줄이기
- **smoothing_factor 조정**: 스무딩 팩터 낮추기

### 3. 카메라 문제
- **권한 확인**: 카메라 접근 권한 확인
- **해상도 조정**: 너무 높은 해상도는 성능 저하 가능

## 🎵 사용 예시

### 기본 사용법
1. 턴테이블을 빈 상태로 두고 프로그램 시작
2. 기준 데이터 수집 완료 대기 (30프레임)
3. 레코드를 놓으면 자동으로 소리 시작
4. 레코드를 빼면 자동으로 소리 중지

### 고급 사용법
1. 다양한 레코드로 테스트
2. 조명 조건에 맞게 임계값 조정
3. 감지 방법 변경으로 최적화
4. 실시간 신뢰도 모니터링
