# 🎵 레코드 감지 사용 가이드

## 📋 현재 상황 분석

### 1. `./run_record_test.sh` 문제점
- **현상**: 빈 화면에서 confidence 0.007 정도만 나오고, 레코드를 올려도 큰 변화 없음
- **원인**: 
  - 임계값이 너무 높음 (0.6 → 0.2로 수정)
  - 감지 민감도가 낮음 (5배 증폭으로 수정)
- **해결**: ✅ 수정 완료

### 4. 첫 번째 실행 문제점
- **현상**: 첫 번째 시작 시 레코드 감지가 안 되고, 정지 후 재시작하면 정상 작동
- **원인**: 
  - 레코드 감지기 초기화 순서 문제 (ROI 설정 전에 감지기 생성)
  - 기준 데이터가 재시작 시에만 제대로 리셋됨
- **해결**: ✅ 수정 완료
  - ROI 설정 후 레코드 감지기 초기화로 순서 변경
  - 정지 시 기준 데이터 자동 리셋 추가
  - 디버그 로그 추가로 문제 추적 가능

### 2. `./run_turntable.sh` 문제점
- **현상**: GUI에서 "기준 수집 중..."만 뜨고 완료되지 않음, 시작 버튼 누르면 에러
- **원인**: 
  - OSC 전송 함수에서 빈 리스트 처리 오류
  - 임계값이 너무 높음
- **해결**: ✅ 수정 완료

### 3. 소리 끄기 문제점
- **현상**: "레코드가 없어 소리를 끕니다" 메시지와 함께 같은 소리가 반복
- **원인**: 
  - 빈 리스트 `[]` 전송으로는 소리가 제대로 끊어지지 않음
  - 전송 간격마다 반복 전송
- **해결**: ✅ 수정 완료
  - 전용 `stop_all_sounds()` 함수 추가
  - 다중 방법으로 소리 끄기 시도
  - 한 번만 전송하도록 플래그 추가

## 🚀 사용 방법

### 1. 레코드 감지 테스트 (`./run_record_test.sh`)

```bash
# 1. conda 환경 활성화
conda activate garden

# 2. 테스트 실행
./run_record_test.sh
```

**테스트 과정:**
1. **기준 수집**: 30프레임 동안 빈 턴테이블 상태 수집
2. **실시간 감지**: 레코드를 놓고 빼면서 실시간 감지
3. **시각적 피드백**: 화면에 ROI 원과 상태 표시

**키보드 조작:**
- `q`: 종료
- `r`: 기준 재설정 (새로운 빈 상태로 기준 변경)
- `t`: 임계값 조정 (0.1 → 0.2 → 0.3... 순환)

**예상 결과:**
- 빈 상태: confidence 0.0~0.1, "❌ 레코드 없음"
- 레코드 있음: confidence 0.3~0.8, "✅ 레코드 있음"

### 2. 메인 턴테이블 GUI (`./run_turntable.sh`)

```bash
# 1. conda 환경 활성화
conda activate garden

# 2. 턴테이블 실행
./run_turntable.sh
```

**GUI 사용 과정:**
1. **모드 선택**: "1" 선택 (카메라 화면과 함께 실행)
2. **GUI 대기**: 카메라 화면이 나타날 때까지 대기
3. **레코드 감지 설정**: 
   - "레코드 감지 활성화" 체크박스 확인
   - "시작" 버튼 클릭
4. **기준 수집**: 30프레임 동안 자동으로 빈 상태 수집
5. **실시간 감지**: 레코드 놓기/빼기로 소리 켜기/끄기

**GUI 컨트롤:**
- **레코드 감지 섹션**:
  - ✅ 레코드 감지 활성화
  - 📊 레코드 상태 표시
  - 📈 신뢰도 표시
  - 🔄 기준 재설정 버튼

## 🔧 문제 해결

### 1. 여전히 감지가 안 되는 경우

**임계값 조정:**
```python
# 더 낮은 임계값으로 설정
detector = create_record_detector(threshold=0.05)
```

**감지 방법 변경:**
```python
# 템플릿 매칭으로 변경 (더 정확하지만 느림)
detector = create_record_detector(method="template_matching")
```

### 2. 너무 민감한 경우

**임계값 높이기:**
```python
# 더 높은 임계값으로 설정
detector = create_record_detector(threshold=0.2)
```

**스무딩 조정:**
```python
# 더 부드러운 결과
detector = create_record_detector(smoothing_factor=0.9)
```

### 3. 카메라 문제

**권한 확인:**
```bash
# macOS에서 카메라 권한 확인
System Preferences → Security & Privacy → Camera
```

**해상도 조정:**
```python
# 더 낮은 해상도로 성능 향상
camera = open_camera(0, 640, 480)
```

## 📊 성능 최적화 팁

### 1. 조명 조건
- **일정한 조명**: 급격한 조명 변화 피하기

- **배경 단순화**: 복잡한 배경 피하기
- **ROI 크기**: 턴테이블 크기에 맞게 조정
- **카메라 거리**: 너무 가깝거나 멀지 않게

### 3. 레코드 특성
- **색상 대비**: 바닥과 색상 차이가 있는 레코드 사용

- **크기**: 너무 작은 레코드는 감지 어려움
